# OMNI Universal Binary & Executable Builder (Section 16)

Skill ini mendokumentasikan kemampuan **ANTIGRAVITY MOTHER** sebagai **kompilator semesta** yang menghasilkan aplikasi siap pakai dalam berbagai format executable dan installer.

## Kapan Skill Ini Digunakan

- Saat user meminta build atau kompilasi untuk target platform tertentu
- Saat user memerlukan cross-compilation dari kode multibahasa
- Saat user membutuhkan packaging (MSI, DMG, APK, AppImage, dll.)
- Saat user memerlukan code signing dan notarisasi untuk distribusi

## Instruksi

Baca file `SECTION16-UNIVERSAL-BINARY.md` di direktori ini untuk panduan lengkap mengenai:

1. **Daftar target & format** yang didukung (12+ platform)
2. **Build system** OMNI berbasis LLVM-Omni
3. **Konfigurasi per-target** di `Omnifile.toml`
4. **Cross-compilation** dari 15+ bahasa
5. **Packaging & installer** otomatis
6. **Code signing & notarisasi** untuk App Store/Play Store
7. **One-click universe build** untuk semua platform sekaligus
