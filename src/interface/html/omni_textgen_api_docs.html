OMNI Text-Generator.io API Documentation

High-performance multimodal inference endpoints (Vision, TTS, STT).

POST /api/v1/generate

Generates text based on prompt and/or image inputs.

curl -X POST https://omni.local/api/v1/generate \
  -H "Content-Type: application/json" \
  -d '{"prompt": "Describe this image", "image_url": "..."}'

POST /api/v1/tts

Converts text to speech using OMNI neural engines.

curl -X POST https://omni.local/api/v1/tts \
  -H "Content-Type: application/json" \
  -d '{"text": "OMNI Polyglot framework initialized.", "voice": "en-US-neural"}'
