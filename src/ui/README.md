# OMNI Interface / UI Layer Engines

This directory contains **user-facing, type-safe frontend and mobile engines**
for building cross-platform interfaces, native mobile apps, and web dashboards.

## Supported Languages
| Language | Idiom | Use Case |
|----------|-------|----------|
| **TypeScript** | `ts::strong_types` | Static typing, full-stack safety |
| **Dart** | `dart::widget` | Cross-platform mobile & web UI |
| **Swift** | `swift::UIKit` | Native Apple ecosystem, spatial computing |
| **HTML** | `@html_template` | Declarative layout, semantic structure |

## Engines
| File | Source Repo | Purpose |
|------|-------------|---------|
| `agent_device_instrumentation.dart` | Agent Device | Mobile instrumentation framework |
| `android_auto_dashboard.html` | Android-Auto-Api | Automotive dashboard projection |
